## 1. 设计概述

本产品采用「微信小程序前端 + 微信云开发后端」的轻后端架构。计算类逻辑（躺平本金、牛马年限）以纯函数实现，既可在前端本地执行，也可在云函数复用；大模型仅承担两件事——估算城市生活费、生成报告文案——这两类调用统一走云函数，前端不持有密钥。

选择该架构的原因：云开发免运维、天然打通微信登录态（如后续需要），MVP 落地快；关键隐私设计是「收入数据不上云」。

## 2. 总体架构

```text
┌──────────────────────────────────────────────┐
│                  微信小程序前端               │
│  选城市 │ 生活费估算 │ 参数输入 │ 结果展示 │ 报告 │
└──────────────┬───────────────────────────────┘
               │ wx.cloud.callFunction
┌──────────────▼───────────────────────────────┐
│                微信云开发（后端）              │
│  云函数 estimateCost   → 大模型估生活费        │
│  云函数 generateReport → 大模型生成报告文案     │
│  （可选）云数据库：常见城市生活费缓存           │
└──────────────┬───────────────────────────────┘
               │ HTTPS
┌──────────────▼───────────────────────────────┐
│              大模型 API（DeepSeek 等）         │
└──────────────────────────────────────────────┘
```

说明：躺平本金、牛马年限的计算在「前端本地纯函数」完成，不上云；只有生活费估算与报告文案需要大模型时，才调用云函数。

## 6. 接口设计（云函数）

统一返回结构：

```json
{ "code": 0, "message": "ok", "data": {} }
```

### 6.1 estimateCost

- 入参：`{ province: string, city: string }`
- 出参：`{ items: [{ name, amount }], total, currency: "CNY", source: "ai" }`
- 内部：先查缓存 → 命中直接返回；未命中构造提示词让大模型以 JSON 返回分项 → 解析校验 → 写缓存。
- 大模型输出须约束为严格 JSON 结构，云函数做格式兜底与异常处理。

### 6.2 generateReport

- 入参：`{ city, cost, targetAsset, years, months, nickname? }`
- 出参：`{ title, body, footer }`
- 隐私约束：不接受也不上传存款、工资字段。
- 内部：拼装提示词要求「轻松诙谐、自嘲但不低俗、不涉敏感」，对返回文案做基础内容安全过滤后返回。

## 7. 关键算法设计（前端本地实现）

### 7.1 躺平本金

```text
A = M * 12 / r
```

- M：月生活费（用户微调后），r：年化收益率（默认 0.04）。
- 返回四舍五入到元。

### 7.2 牛马年限

```text
S = max(0, W - M)         // 月可储蓄
i = r / 12                // 月利率

若 D >= A：T = 0（已可躺平）
若 S == 0 且 D < A：T = Infinity（无法通过当前收入攒够）
否则：二分法或对数求解 T，使
  D*(1+i)^T + S*((1+i)^T - 1)/i = A
```

- D：存款，W：税后月工资。
- 使用二分法在 [0, 1200] 月范围内求解（上限 100 年），避免对数公式的数值问题。
- 结果向下取整，换算「X 年 Y 个月」。
- 算法实现为纯函数 calcFIRE({ M, r, D, W })，前端与云函数共用同一份实现，便于测试与一致性。

## 9. 安全与合规设计

1. 密钥管理：大模型 API 密钥仅存于云函数环境变量，不下发前端。
2. 隐私隔离：存款、工资仅前端本地计算，不上传；报告接口只接收脱敏后的计算结论。
3. 免责声明：结果页、报告页显著展示「娱乐测算，仅供参考，不构成投资理财建议」。
4. 内容安全：报告话术经基础过滤；「牛马」等词控制在自嘲幽默尺度，避免低俗与敏感表达。
5. 调用治理：生活费结果按城市缓存，设置单次 token 上限与超时，控制成本。
6. 若后续引入用户体系或云端存储，需补充隐私政策与授权，本期 MVP 不采集精确收入。
