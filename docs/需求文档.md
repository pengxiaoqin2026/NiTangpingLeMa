## 1. 项目概述

### 1.1 背景

学生在日常学习中会产生大量错题，传统做法是手工抄题、贴错题本，效率低且容易遗漏解题过程。家长和老师也希望能按年级、学科沉淀错题，便于复习和跟踪薄弱点。

本小程序希望通过「拍照 → OCR 识别 → 自动补答案与思路 → 归类成册」的方式，把错题整理这件事变得几乎无感。

### 1.2 产品目标

1. 用户拍照或从相册上传错题图片，系统自动识别题目内容。
2. 自动提取图片中已有的解题答案；若图片中没有答案，自动联网搜索答案并生成解题思路。
3. 错题按「错题集（标题 / 文件标识）」组织，支持按年级、学科等维度分类，例如「一年级」「二年级」「三年级数学」。
4. 用户可随时浏览、检索、复习已收录的错题。

### 1.3 产品定位与范围

- 定位：面向学生 / 家长 / 老师的一站式错题整理与复习工具。
- 本期范围（MVP）：错题录入、OCR 识别、答案补齐、错题集管理、浏览检索。
- 非本期范围：错题打印、错题组卷、社交分享、多端（APP / 网页）同步。

## 2. 目标用户与使用场景

### 2.1 用户画像

| 角色 | 特征 | 核心诉求 |
| --- | --- | --- |
| 学生 | 小学 / 初高中学生，使用手机 | 快速收录错题，复习时查看答案和思路 |
| 家长 | 帮孩子整理错题 | 按年级 / 学科分类，长期沉淀 |
| 老师 | 批改后引导学生整理 | 分类清晰、便于检查学生错题集 |

### 2.2 核心使用场景

1. 场景 A：学生做完作业，对错题拍照，自动识别题目、答案与思路，一键存入「三年级数学」错题集。
2. 场景 B：家长拍下试卷上只有题目、没有答案的错题，系统自动联网找到答案并附解题思路。
3. 场景 C：期末复习时，学生打开「一年级」错题集，按学科 / 掌握程度筛选错题逐题复习。

## 3. 功能需求

### 3.1 功能总览

核心链路为：登录授权 → 新建 / 选择错题集 → 拍照或上传 → OCR 识别 → 人工校对 → 答案补齐（缺答案时联网搜索）→ 保存入册。

### 3.2 功能详细说明

#### F1 微信授权登录

- 用户首次进入自动发起微信授权，获取 openid 作为用户唯一标识。
- 无注册 / 密码流程，登录态由微信生态保障。
- 需要用户授权头像昵称（可选），用于展示；不授权也可正常使用。

#### F2 错题录入（拍照 / 相册上传）

- 支持「拍照」与「从相册选择」两种方式（调用 `wx.chooseMedia`）。
- 支持一次选择多张图片（上限建议 9 张），每张图片作为一条独立错题处理。
- 上传前在本地做图片压缩与旋转矫正，降低流量和 OCR 成本。
- 支持常见图片格式（jpg / png / heic 转码）。

#### F3 OCR 识别与解析

- 对上传图片进行 OCR 识别，识别印刷体与手写体文字。
- 从识别结果中结构化提取：
  - 题目内容（题干）；
  - 已有答案（若图中包含）；
  - 已有解题过程 / 步骤（若图中包含）。
- 识别结果进入「校对页」，用户可编辑、修正识别错误后再保存。
- 识别失败（无文字、图片模糊）时给出明确提示，支持重试或手动录入。

#### F4 答案补齐与解题思路（核心能力）

- 判断逻辑：图片中是否已提取到答案。
  - 有答案：保留答案，仅补全 / 生成「解题思路」（可开关）。
  - 无答案：自动联网搜索答案，并生成解题思路。
- 联网搜索能力通过小程序后端（云函数）实现，前端不直接爬取网页。
- 输出结果包含：答案、解题思路 / 步骤，且标注来源（供用户判断可信度）。
- 所有自动生成内容允许用户人工编辑后再保存。

#### F5 错题集管理（标题 / 文件标识）

- 每个错题集包含：标题（如「一年级」「三年级数学」）、年级、学科、封面、创建时间。
- 支持新建、重命名、删除错题集。
- 保存错题时必须归属到一个错题集；支持保存时快速新建错题集。
- 建议提供常用年级 / 学科预设，减少输入成本。

#### F6 错题浏览、搜索与筛选

- 按错题集浏览错题列表，支持分页 / 下拉加载。
- 支持关键词搜索题干。
- 最上层的目录级别是年级，年级下支持按学科、掌握程度、标签、收录时间筛选。
- 错题详情展示：原图、题目、答案、解题思路、来源、收录时间。

#### F7 错题编辑与删除

- 支持编辑题目的文字内容、答案、解题思路、所属错题集、标签。
- 支持删除单条错题、批量删除。
- 删除前二次确认。

#### F8 复习模式（P1，本期可选）

- 错题卡片式翻页复习，可标记「已掌握 / 未掌握」。
- 支持按错题集随机 / 顺序复习。

### 3.3 功能优先级

| 优先级 | 功能 | 说明 |
| --- | --- | --- |
| P0（MVP 必做） | F1 登录、F2 录入、F3 OCR、F4 答案补齐、F5 错题集、F6 浏览检索、F7 编辑删除 | 核心闭环 |

## 5. 非功能需求

### 5.1 性能

- 单张图片本地压缩后建议 ≤ 1MB，上传耗时可控。
- OCR 识别单图目标 ≤ 5 秒（受第三方服务影响）。
- 答案补齐（联网搜索）目标 ≤ 15 秒，需有加载态与超时提示。
- 列表分页加载，首屏 ≤ 3 秒。

### 5.2 安全与隐私合规

- 用户上传的图片与错题数据仅本人可见，按 openid 隔离。
- 遵循《微信小程序运营规范》与个人信息保护要求：首次使用前展示隐私政策，说明图片、识别内容的用途。
- 图片存储使用私有读权限，通过临时链接访问。
- 云函数密钥不下发到前端，敏感调用在服务端完成。

### 5.3 可用性

- 识别失败、搜索无结果、网络异常均需有友好提示与重试入口。
- 自动生成内容必须有「人工校对 / 编辑」环节，避免错误答案误导用户。

### 5.4 兼容性

- 覆盖主流机型与微信基础库（建议最低基础库按云开发要求设置）。
- 支持 iOS / Android。

## 6. 约束与假设

- 假设：用户已注册微信，可正常登录小程序。
- 假设：OCR 采用第三方云服务，需申请对应账号与密钥【待确认，见技术选型】。
- 假设：联网搜题采用「云函数 + 大模型 / 题库接口」，需确认供应商与预算【待确认】。
- 约束：小程序无独立注册体系，以微信 openid 为账号。
- 约束：小程序包体大小、域名白名单等需符合微信平台要求。

## 7. 验收标准

1. 用户可完成「拍照 / 相册上传 → OCR → 校对 → 保存」完整闭环。
2. 无答案图片可自动返回答案与解题思路，并标注来源。
3. 错题集可按标题 / 年级 / 学科组织与检索。
4. 识别错误可人工修正，修改结果正确持久化。
5. 数据按用户隔离，他人无法访问。
6. 核心流程在常见机型上运行流畅，无白屏、无未捕获异常。
